## Open-Source Tools

### [gstin-validator](https://github.com/paytaxs/gstin-validator)
A small, dependency-free Python tool that checks whether a GSTIN has a valid **format and checksum**.

> It checks structure only. It cannot confirm that a registration is active, cancelled or suspended. Always verify on the official [GST portal](https://www.gst.gov.in) (Services > Search Taxpayer).
